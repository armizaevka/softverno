# Publish — Softverno / Tutor (Google Play)

Материалы для первой и последующих публикаций в Google Play.

| Папка | Содержание |
|---|---|
| [`play-store/`](play-store/) | Чеклист до AAB, store listing, блокеры Production |
| [`data-safety/`](data-safety/) | Черновик ответов формы Data Safety |

**Не входит:** исходники Android, keystore, секреты, APK/AAB.

Связанные URL продукта: [softverno.ru](https://softverno.ru), [privacy](https://softverno.ru/privacy), [terms](https://softverno.ru/terms).
